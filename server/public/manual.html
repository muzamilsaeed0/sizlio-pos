Sizlio POS - User Manual

1. System overview

Sizlio is a cloud POS for restaurants in Pakistan. One account can run Full POS, Cafe Lite, or Wholesale depending on plan.

سسٹم کا تعارف: سزلیو پاکستان میں ریسٹورنٹس کے لیے کلاؤڈ POS ہے۔ ایک اکاؤنٹ پلان کے مطابق فل POS، کیفے لائٹ یا ہول سیل چلا سکتا ہے۔

Order types: Dine-in (table), Walk-in/Takeaway, Delivery.

آرڈر کی اقسام: ڈائن اِن (ٹیبل)، واک اِن/ٹیک اوے، ڈیلیوری۔

2. Login

  1. Open your role URL shared by the manager.
  2. Enter username and password (staff passwords are 4–8 characters).
  3. If asked to change password on first login, set a new one.
Note: Avoid logging multiple roles in the same browser session to prevent unexpected logouts.

نوٹ: ایک ہی براؤزر سیشن میں کئی رولز لاگ اِن کرنے سے بچیں تاکہ اچانک لاگ آؤٹ نہ ہو۔

3. Manager screen

Manager controls sales, menu, staff, inventory, suppliers, refunds, settings, FBR, and table QR.

مینیجر سیلز، مینو، اسٹاف، انوینٹری، سپلائرز، ریفنڈز، سیٹنگز، FBR اور ٹیبل QR کنٹرول کرتا ہے۔

3.1 Sales & Profit

  • Sales — today, month, or custom date range.
  • Profit — Revenue, COGS (recipes × purchase price), Gross Profit, Margin %. Print & CSV available.
سیلز — آج، مہینہ، یا کسٹم تاریخ۔ منافع — آمدنی، COGS (ریسیپی × خرید قیمت)، مجموعی منافع، مارجن٪۔ پرنٹ اور CSV۔
Note: COGS is accurate only when menu items have kitchen recipes and inventory has purchase prices.

نوٹ: COGS تب درست ہوتا ہے جب مینو آئٹمز کی ریسیپی ہو اور انوینٹری پر خرید قیمت ہو۔

3.2 Menu

  1. Menu → Items: add name, category, price.
  2. Categories: manage allowed categories.
  3. Deals/Combos: set deal price and included items.
مینو → آئٹمز: نام، کیٹیگری، قیمت۔ کیٹیگریز: مینج کریں۔ ڈیلز: قیمت اور شامل آئٹمز۔

3.3 Staff

  1. Staff → Add: name, username, password (4–8 chars), role.
  2. Reset password from Staff edit (4-8 characters).
  3. Deactivate staff who left so they cannot log in.
اسٹاف شامل کریں: نام، یوزرنیم، پاس ورڈ، رول۔ پاس ورڈ ری سیٹ کریں۔ جوہڑک والے اسٹاف کو ڈی ایکٹیویٹ کریں۔

3.4 Inventory & Suppliers

  • Inventory: add items with unit, stock, min stock, purchase price, supplier.
  • Stock in/out transactions for adjustments.
  • Suppliers: create with phone/address; balances show on list.
انوینٹری: یونٹ، اسٹاک، کم از کم اسٹاک، خرید قیمت، سپلائر۔ اسٹاک اِن/آؤٹ۔ سپلائرز بنائیں۔

3.5 Kitchen requests

  1. Kitchen requests stock from warehouse.
  2. Manager → Kitchen Requests → Approve or Reject.

Approve transfers quantity from warehouse inventory to kitchen inventory.

کچن گودام سے اسٹاک مانگتا ہے۔ مینیجر منظور یا مسترد کرے۔ منظوری پر مقدار گودام سے کچن انوینٹری میں منتقل ہوتی ہے۔

3.6 Refunds

  1. Counter requests refund on paid served/delivered order with reason.
  2. Manager → Refund Requests → Pending.
  3. Approve → payment becomes refunded (excluded from sales). Reject keeps order paid.
کاؤنٹر ریفنڈ مانگے۔ مینیجر → ریفنڈ درخواستیں → Pending۔ منظوری پر payment_status = refunded ہو جاتا ہے۔
Note: Refund does not return ingredients to kitchen stock. Food is treated as already used.

نوٹ: ریفنڈ پر کچن اسٹاک واپس نہیں ہوتا۔ کھانا استعمال شدہ سمجھا جاتا ہے۔

3.7 Table QR & Settings

  • Generate and print table QR codes; set GPS while inside the restaurant.
  • Settings: GST, tax, delivery/dine/card charges, discounts.
  • FBR Setup: enable when you have live FBR credentials.
ٹیبل QR بنائیں اور پرنٹ کریں؛ ریسٹورنٹ کے اندر GPS سیٹ کریں۔ سیٹنگز: ٹیکس، ڈیلیوری/ڈائن/کارڈ چارجز۔ FBR سیٹ اپ۔

4. Counter

  1. Select Dine-in, Walk-in, or Delivery.
  2. Add items/deals. For dine-in set table; for delivery set phone & address.
  3. Pay Now (Cash/Card) or Pay Later.
  4. After kitchen ready: handover / wait for waiter serve / assign rider as needed.
  5. Mark Paid (if needed) → Mark Completed. Or Request Refund before/after as policy allows.
1. ڈائن اِن، واک اِن یا ڈیلیوری چنیں۔
2. آئٹمز شامل کریں۔ ڈائن اِن پر ٹیبل؛ ڈیلیوری پر فون اور ایڈریس۔
3. Pay Now یا Pay Later۔
4. کچن ریڈی کے بعد: ہینڈ اوور، ویٹر سرو، یا رائیڈر اسائن۔
5. Mark Paid → Mark Completed یا Request Refund۔

Cancellation: Cancel only before served/completed — releases inventory reservation.

Cancel صرف serve/complete ہونے سے پہلے — انوینٹری ریزرویشن ریلیز ہو جاتی ہے۔

5. Kitchen (KDS)

  1. Start shift.
  2. Confirm order (prep minutes) → preparing.
  3. Mark Ready when done.
  4. Maintain recipes for each menu item.
  5. Request stock when low; end shift to see totals.
شفت شروع کریں۔ آرڈر کنفرم کریں (تیاری کے منٹ) → preparing۔ تیار ہونے پر Mark Ready۔ ہر مینو آئٹم کی ریسیپی رکھیں۔ اسٹاک کم ہو تو درخواست دیں؛ شفت اینڈ پر ٹوٹل دیکھیں۔

6. Waiter, Rider, Status

  • Waiter: Serve ready dine-in orders to the table.
  • Rider: Take assigned delivery; counter marks out-for-delivery / delivered / COD.
  • Status board: Show order progress on a display screen.
ویٹر: ریڈی ڈائن اِن آرڈر ٹیبل پر سرو کریں۔ رائیڈر: اسائنڈ ڈیلیوری لیں؛ کاؤنٹر آؤٹ فار ڈیلیوری / ڈیلیورڈ / COD مارک کرے۔ اسٹیٹس بورڈ: ڈسپلے پر آرڈر کی پیش رفت دکھائیں۔

7. Customer QR order

  1. Guest scans table QR.
  2. Must be inside GPS radius set by manager on site.
  3. Place order → kitchen/waiter dine-in flow for that table.
مہمان ٹیبل QR اسکین کرے۔ مینیجر کے سیٹ کردہ GPS دائرے کے اندر ہونا ضروری ہے۔ آرڈر پلیس → اس ٹیبل کا کچن/ویٹر فلو۔

8. Example flows

  • Walk-in Pay Now: Counter pay → Kitchen confirm/ready → Handover → Complete.
  • Dine-in Pay Later: Counter place → Kitchen → Waiter Serve → Counter Pay → Complete.
  • Delivery COD: Counter place → Kitchen → Assign rider → Out → Delivered → Pay → Complete.
واک اِن Pay Now: کاؤنٹر ادائیگی → کچن → ہینڈ اوور → مکمل۔
ڈائن اِن Pay Later: کاؤنٹر → کچن → ویٹر سرو → کاؤنٹر ادائیگی → مکمل۔
ڈیلیوری COD: کاؤنٹر → کچن → رائیڈر → آؤٹ → ڈیلیورڈ → ادائیگی → مکمل۔

9. Cafe Lite & Wholesale

  • Cafe Lite: One counter-lite screen + optional rider; no full waiter/kitchen daily screens.
  • Wholesale: wholesale.html for products, stock, cash sale, invoices — not table service.
کیفے لائٹ: ایک کاؤنٹر لائٹ اسکرین + آپشنل رائیڈر؛ مکمل ویٹر/کچن روزمرہ اسکرین نہیں۔
ہول سیل: پروڈکٹس، اسٹاک، کیش سیل، انوائسز — ٹیبل سروس نہیں۔

10. Troubleshooting

Problem Try / Solution
Unexpected logout One role per browser session.
QR order blocked Set GPS inside restaurant.
Profit COGS low Add recipes + purchase prices.
Cannot cancel Already served — use refund if paid.
Refund missing in sales Correct — refunded excluded.
Staff password error Password must be 4-8 characters.
Delivery stuck Assign rider before Out for delivery.
Support: sizlio.com — share restaurant ID, screen, time, and screenshot when reporting issues.

سپورٹ: sizlio.com — مسئلہ بتاتے وقت ریسٹورنٹ ID، اسکرین، وقت اور اسکرین شاٹ بھیجیں۔
