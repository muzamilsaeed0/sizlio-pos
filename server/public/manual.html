1. System overview

۱۔ سسٹم کا تعارف

Sizlio is a cloud POS for restaurants in Pakistan. One account can run Full POS, Cafe Lite, or Wholesale depending on plan.

سزلیو پاکستان میں ریسٹورنٹس کے لیے کلاؤڈ POS ہے۔ پلان کے مطابق Full POS، Cafe Lite یا Wholesale چل سکتا ہے۔

2. Login

۲۔ لاگ اِن

  1. Open your role URL shared by the manager.
  2. Enter username and password (staff passwords are 4–8 characters).
  3. If asked to change password on first login, set a new one.

اپنے رول کا لنک کھولیں، یوزرنیم/پاس ورڈ لکھیں (اسٹاف پاس ورڈ ۴–۸ حروف)۔

Note: Avoid logging multiple roles in the same browser session — it can cause unexpected logouts.
ایک ہی براؤزر سیشن میں کئی رولز لاگ اِن نہ کریں۔

3. Manager screen

۳۔ مینجر اسکرین

Live: Manager dashboard (FOOD HUB) — Sales Summary + Table QR

Manager controls sales, menu, staff, inventory, suppliers, kitchen requests, refunds, settings, FBR, and table QR.

مینجر سیلز، مینو، اسٹاف، انوینٹری، سپلائرز، کچن درخواستیں، ریفنڈز، سیٹنگز، FBR اور ٹیبل QR سنبھالتا ہے۔

3.1 Sales & Profit

  • Sales — today, month, or custom dates.
  • Profit — Revenue, COGS (recipes × purchase price), Gross Profit, Margin %. Print & CSV available.

منافع تب درست ہے جب ریسیپی اور انوینٹری خرید قیمت سیٹ ہوں۔

Note: Items without recipes understate COGS. Add recipes in Kitchen.

3.2 Menu

  1. Menu → Items — name, category, price.
  2. Categories — manage allowed categories.
  3. Deals / Combos — deal price and included items.

3.3 Staff

  1. Add staff: full name, username, password (4–8 chars), role.
  2. Reset password from Staff edit.
  3. Deactivate staff who left.

اسٹاف پاس ورڈ ۴ سے ۸ حروف۔ چھوڑنے والے اکاؤنٹ ڈی ایکٹیویٹ کریں۔

3.4 Inventory & Suppliers

  • Add inventory with unit, stock, min stock, purchase price, supplier.
  • Stock in/out for adjustments.
  • Suppliers: create with phone/address; balances show on list.

3.5 Kitchen requests

Kitchen requests stock → Manager Approves (transfers warehouse → kitchen) or Rejects.

کچن اسٹاک مانگے → مینجر منظور کرے تو گودام سے کچن میں منتقل۔

3.6 Table QR & Settings

  • Generate table QR codes and print them.
  • Set GPS while inside the restaurant for QR radius checks.
  • Settings: GST, tax, delivery/dine/card charges, discounts.
  • FBR Setup when you have live credentials.

4. Counter

۴۔ کاؤنٹر

Live-style: Counter POS — today orders, pay now/later, refunded orders visible

  1. Select Dine-in, Walk-in, or Delivery.
  2. Add items / deals. Dine-in: table. Delivery: phone + address.
  3. Pay Now (Cash/Card) or Pay Later.
  4. After kitchen ready: handover / waiter serve / assign rider.
  5. Mark Paid if needed → Mark Completed. Or Request Refund.

آرڈر ٹائپ چنیں، آئٹمز شامل کریں، Pay Now یا Later، پھر فلو مکمل کریں۔

Cancel only works before served/completed — releases inventory reservation.

5. Kitchen (KDS)

۵۔ کچن

Kitchen — confirm, ready, recipes, stock, shift end

  1. Start shift.
  2. Confirm order (prep minutes) → preparing.
  3. Mark Ready when done.
  4. Maintain recipes (menu item → ingredients + qty).
  5. Request stock when low. End shift for totals + ingredient cost.

شفٹ شروع → کنفرم → ریڈی → ریسیپی اور اسٹاک درخواست۔

6. Waiter, Rider, Status

۶۔ ویٹر، رائڈر، سٹیٹس

  • Waiter: Serve ready dine-in orders to the table.
  • Rider: Assigned deliveries; counter marks out-for-delivery / delivered / COD.
  • Status board: Show order progress on a display screen.

ویٹر سرف کرے؛ رائڈر ڈیلیوری لے؛ سٹیٹس بورڈ ڈسپلے پر چلے。

7. Customer QR order

۷۔ کسٹمر QR آرڈر

  1. Guest scans table QR.
  2. Must be inside GPS radius set by manager on site.
  3. Place order → kitchen / waiter dine-in flow for that table.
If order says “outside radius”, manager must set location while standing in the restaurant.

8. Example flows

۸۔ مثال کے فلو

Walk-in Pay Now: Counter pay → Kitchen confirm/ready → Handover → Complete
Dine-in Pay Later: Counter place → Kitchen → Waiter Serve → Counter Pay → Complete
Delivery COD: Counter place → Kitchen → Assign rider → Out → Delivered → Pay → Complete

واک اِن ادائیگی کے ساتھ؛ ڈائن اِن بعد میں ادائیگی؛ ڈیلیوری COD۔

9. Refunds

۹۔ ریفنڈز

Live data: Refund Requests → Approved (#323, #325, #324)

  1. Counter: on paid served/delivered order → Request Refund + reason.
  2. Manager → Refund Requests → Pending.
  3. Approve → payment_status becomes refunded (excluded from sales).
  4. Reject → order stays paid.

کاؤنٹر درخواست → مینجر منظور/مسترد۔ منظور پر سیلز سے باہر۔

Refund does not return ingredients to kitchen stock (food already prepared).

View approved refunds: Manager → Refund Requests → Approved.

10. Cafe Lite & Wholesale

۱۰۔ کیفے لائٹ اور ہول سیل

Cafe Lite: single counter-lite screen + optional rider. No full waiter/kitchen daily screens.

کیفے لائٹ: ایک کاؤنٹر اسکرین + اختیاری رائڈر۔

Wholesale: wholesale.html — products, stock, cash sale, invoices (not table service).

ہول سیل: پروڈکٹس، اسٹاک، کیش سیل، انوائس۔
